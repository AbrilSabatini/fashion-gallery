# Fashion Gallery

> Minimalist fashion image gallery. Upload, preview, and manage your archive.
 
**Live:** [https://abrilsabatini.github.io/fashion-gallery](https://abrilsabatini.github.io/fashion-gallery)
 
---
 
## Tech Stack
 
- **HTML + CSS + Vanilla JavaScript** — no frameworks, no dependencies
- **GitHub Pages** — static site hosting

## Next Steps
 
This project was intentionally built with plain HTML, CSS, and JavaScript to focus on core functionality. The natural next step would be to migrate to a frontend framework such as **React** or **Vue** to:
 
- Replace hardcoded configuration with proper **environment variables** (e.g. `VITE_API_URL`)
- Break the UI into reusable **components**
- ...
